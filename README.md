Lightweight google chrome/edge extension that translates some words on a page to another language of your choosing to learn that language. Hovering over the translated word shows the English version.

Install Instructions: 
Unzip file, go to you "manage extensions" on google chrome or edge.
Turn on developer mode on the bottom left.
Go to the top of the page and press "load unpacked".
Open the unzipped file "word wizard".
Enable extension.
